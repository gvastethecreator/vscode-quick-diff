## Highlights

- Compare a selection or complete buffer with clipboard text.
- Save a selection as the left side of a later comparison.
- Compare any two open text files.
- Use immutable in-memory documents with no temporary files or custom diff UI.

## Use

Open the Command Palette and run a **Quick Diff** command. **Compare Selection with Clipboard** is also available from the editor context menu.

Compared text stays in memory and is cleared when the extension deactivates. Quick Diff has no telemetry, network calls, persistence, clipboard watcher, or filesystem writes. It supports desktop, web, virtual, restricted, and remote workspaces on VS Code 1.134 or newer.
